# ShopNest 🛍️

ShopNest is a front-end e-commerce website project built using HTML, CSS, and JavaScript.

## Features

- Multiple website pages
- Product listing and details pages
- Shopping cart interface
- Checkout page
- Contact page

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
shopnest/
├── index.html
├── products.html
├── product-details.html
├── cart.html
├── checkout.html
├── contact.html
├── css/
│   └── style.css
└── js/
    ├── app.js
    └── data.js
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
